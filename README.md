# Средневековый замок

Учебный проект на C++17, GLFW 3 и GLAD 1 с контекстом OpenGL 2.1.
Все функции сцены находятся в main.cpp. GLAD уже включён в vendor/glad.

## Запуск на Xubuntu

Установите системные зависимости:

```bash
sudo apt update
sudo apt install build-essential cmake libglfw3-dev libgl1-mesa-dev
```

Распакуйте архив, откройте папку castle_project в VS Code.
Расширения Microsoft: C/C++ и CMake Tools.
В терминале VS Code из этой папки:

```bash
cmake -S . -B build -DCMAKE_BUILD_TYPE=Debug
cmake --build build -j2
./build/castle
```

Повторная сборка после изменения кода: `cmake --build build -j2`.
Для запуска через палитру VS Code выберите CMake: Select a Kit → GCC,
затем CMake: Build и CMake: Run Without Debugging (цель castle).
Рабочая папка запуска не важна: внешних ресурсов нет.

## Управление

- Левая кнопка мыши и перетаскивание — вращение камеры вокруг замка.
- Колесо — приближение и отдаление.
- Пробел — плавно поднять или опустить мост; повторное нажатие меняет направление.
- L — длина стен от 14 до 24, шаг 2. Начальное значение 18.
- P — шаг зубцов от 0.8 до 1.8, шаг 0.2. Начальное значение 1.2.
- R — исходное положение камеры.
- Esc — закрыть окно.

## Реализовано

Стены с процедурными зубцами, круглые и квадратные башни с коническими
крышами, сквозные арочные ворота, ров по всему периметру, вода,
генерируемая каменная текстура, освещение и подъёмный мост.
Изменение длины перестраивает стены, башни, ров, дорогу и шарнир моста.
Генерация процедурная и детерминированная: задаётся параметрами, не случайностью.

## Намеренные упрощения

Вода непрозрачная и неподвижная. Нет физики, столкновений камеры,
теней, цепей моста и загрузки моделей. Материалы крыши и дерева задаются цветом.
Каменная текстура создаётся программно через glTexImage2D, это настоящая
текстура OpenGL, а не отдельная геометрия каждого камня.
GLM не нужен: используются знакомые glTranslatef, glRotatef, glFrustum.

## Если не запускается

- glfw3 not found: установите libglfw3-dev, повторите конфигурацию CMake.
- Не найден glad/glad.h: открывайте весь проект, сохраняйте папку vendor.
- Failed to create window или ошибка GLFW: запускайте в графическом сеансе
  Xubuntu; проверьте видеодрайвер командой glxinfo -B (пакет mesa-utils).
- Не заменяйте GLAD на вариант Core и не задавайте GLFW_OPENGL_CORE_PROFILE:
  учебный код использует glBegin, glMatrixMode и фиксированное освещение.
- При переносе с Windows не используйте старую папку build.

GLAD 0.1.36 сгенерирован для OpenGL 2.1; исходные уведомления сохранены.

## Как изучать код

Откройте Castle_Architecture.docx рядом с main.cpp. В Word есть кликабельное
содержание и ссылки обратно к нему. Номера [01]–[10] совпадают с кодом.
В VS Code ищите номер блока или имя функции через Ctrl+F.

Начните с [01] настроек, затем [04] стены и [08] моста.
В [02] собраны вспомогательные фигуры; к ним можно вернуться позже.
Главный цикл расположен в [10]. Подробные примеры изменений и упражнения
находятся в руководстве. Все единицы длины условные.

## Стрелы из башен — блок [11]

После полного подъёма моста в двух передних башнях открываются объёмные
углубления. Каждая башня выпускает простые стрелы по параболе в сторону +Z.
При опускании моста новые выстрелы прекращаются, старые стрелы долетают
до уровня земли и удаляются. Клавиша управления осталась прежней: пробел.

Настройки в начале main.cpp: arrowShotInterval (пауза), arrowForwardSpeed
(скорость вперёд), arrowUpwardSpeed (скорость вверх), arrowGravity (тяжесть).
Объяснения нового кода: разделы 8–9 в Castle_Architecture.docx.
Дополнительные библиотеки и файлы ресурсов не нужны.
Чтобы видеть всю дальность полёта, отдали камеру колёсиком мыши.
